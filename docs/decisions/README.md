# Decyzje

Jeden plik na decyzję: `YYYY-MM-DD-krotki-slug.md`.

Format:

```markdown
# Tytuł decyzji

- **Decyzja:** co postanowiono
- **Kontekst:** jaki problem to rozwiązuje / co ją wywołało
- **Alternatywy:** co odrzucono i dlaczego (opcjonalnie)
- **Status:** aktywna / zmieniona przez [link do nowszej decyzji]
```

Decyzji się nie nadpisuje. Jeśli coś się zmienia — nowy plik, stary dostaje `Status: zmieniona przez ...`.
