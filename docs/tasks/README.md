# Plany tasków

Jeden plik na task w toku: `nazwa-taska.md`. Aktualizowany na bieżąco — po to, by wznowić pracę po resecie sesji bez odtwarzania kontekstu od zera.

Format:

```markdown
# Nazwa taska

- **Cel:** co ma powstać, w jednym zdaniu
- **Status:** w toku / gotowe / zablokowane (+ na czym)

## Plan
- [ ] krok 1
- [ ] krok 2

## Decyzje po drodze
Krótkie noty; jeśli coś istotne architektonicznie — osobny plik w `/docs/decisions/`.
```

Plik zostaje po ukończeniu taska jako historia — nie usuwać.
